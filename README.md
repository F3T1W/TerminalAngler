# Спутник у озера / Lake Companion

Небольшая терминальная RPG о рыбалке и прогулках вокруг озера. Игра запускается локально: основная механика, сохранения и карта не требуют аккаунтов, облака или сетевых сервисов. Ollama, музыка и голос — необязательные дополнения.

Полный дизайн-документ: [docs/GDD.md](docs/GDD.md). План будущих обновлений и версий: [docs/ROADMAP.md](docs/ROADMAP.md).

## Быстрый запуск

Нужен Git и .NET SDK `10.0.203` или совместимый SDK .NET 10. Точная версия закреплена в [global.json](global.json).

```sh
git clone <URL-репозитория>
cd TerminalAngler
dotnet restore LakeCompanion.sln
dotnet build LakeCompanion.sln --no-restore
dotnet run --project src/LakeCompanion.Console
```

В Rider открой `LakeCompanion.sln`, выбери запуск `LakeCompanion.Console` и нажми Run. После изменения кода останови старый процесс красным квадратом и запусти его заново.

Игра будет работать и без Ollama: Рован ответит подготовленными репликами. На macOS также заработает фоновая музыка; без собственных треков игра создаст и зациклит локальный эмбиент.

## Управление

- Стрелки или `WASD` — ходьба по берегу. В воду и за границу карты зайти нельзя.
- `F` — рыбалка. После поклёвки повтори три показанные стрелки строго по порядку до конца общего таймера.
- `T` — написать Ровану сообщение.
- `V` — сказать сообщение в микрофон, если настроен голосовой ввод.
- `O` — включить или выключить озвучку ответов Рована.
- `R` — отдохнуть.
- `M` — поставить музыку на паузу или продолжить с того же места.
- `Q` — выйти. Прогресс также сохраняется после действий и перемещений.

## Диалог с Ollama (необязательно)

По умолчанию игра использует локальный сервер Ollama на `http://localhost:11434` и модель `llama3.2:3b`.

1. Установи Ollama с [ollama.com](https://ollama.com).
2. В терминале выполни:

   ```sh
   ollama pull llama3.2:3b
   ```

3. Запусти приложение Ollama или сервер:

   ```sh
   ollama serve
   ```

Если `ollama serve` сообщает, что порт `11434` уже занят, второй сервер запускать не нужно: Ollama уже работает. Проверить модель можно командой `ollama list`.

Параметры сервера, модели и предел ожидания находятся в [appsettings.json](src/LakeCompanion.Console/appsettings.json), секция `Ollama`. При недоступном сервере игра не зависает и использует локальную запасную реплику.

## Музыка

Музыка сейчас воспроизводится на macOS через системный `afplay`. Дефолтный `assets/music/ambient.mp3` входит в репозиторий и будет в каждом клоне. Пользовательские аудиофайлы, кроме этого трека, не хранятся в Git.

- Положи `.wav`, `.m4a`, `.mp3`, `.aac`, `.aiff` или `.aif` в `assets/music/`.
- Пересобери или перезапусти игру: эти файлы копируются рядом с исполняемым файлом и проигрываются в алфавитном порядке по кругу.
- Дефолтный `assets/music/ambient.mp3` проигрывается по кругу, если рядом нет других треков.
- Если удалить и этот файл, игра создаст локальный WAV-эмбиент в папке данных приложения и воспроизведёт его по кругу.

Громкость и пути настраиваются в секции `AmbientMusic` файла `appsettings.json`. Нажатие `M` освобождает аудиоустройство, поэтому не должно мешать голосу Рована в наушниках.

## Голосовой ввод и озвучка (macOS, необязательно)

Текстовый разговор через `T` всегда доступен. Для `V` требуется `ffmpeg` и разрешение на микрофон у Terminal или Rider:

```sh
brew install ffmpeg
ffmpeg -f avfoundation -list_devices true -i ""
```

Во втором выводе найди номер нужного аудиовхода и укажи его в `src/LakeCompanion.Console/appsettings.json`:

```json
"AudioDevice": "none:2"
```

Здесь `2` — пример номера микрофона. При первом успешном голосовом запросе Whisper может скачать локальную модель распознавания в `~/Library/Application Support/LakeCompanion/models/`. Эта модель и записи микрофона не добавляются в репозиторий.

Озвучка ответов работает через встроенную macOS-команду `say`; включай её клавишей `O`. Звук идёт на текущее устройство вывода macOS. Если голос `Milena` отсутствует, посмотри доступные голоса командой `say -v '?'` и укажи установленный русский голос в `CompanionSpeech:Voice` файла `appsettings.json`.

## Сохранения и локальные данные

Сохранение игры находится вне репозитория:

```text
~/Library/Application Support/LakeCompanion/save.json
~/Library/Application Support/LakeCompanion/lake-companion.db
```

В JSON сохраняется полный снимок: позиции игрока и Рована, уровень и опыт, отношения и пойманная рыба. Удали `save.json` и `lake-companion.db`, если хочешь начать новую игру.

## Что должно быть в Git

Исходники из `src/`, файлы решения, `docs/`, `README.md`, `appsettings.json` с безопасными значениями по умолчанию, `assets/music/README.md` и `assets/music/ambient.mp3` — это часть проекта и их следует закоммитить. `.gitignore` исключает только результаты сборки, настройки IDE, локальные модели/сохранения и дополнительную пользовательскую музыку.

## Структура

```text
src/LakeCompanion.Domain/          Сущности и сохраняемое состояние
src/LakeCompanion.Application/     Правила компаньона и интерфейсы сервисов
src/LakeCompanion.Infrastructure/  Ollama, SQLite, JSON-сохранения, музыка и голос
src/LakeCompanion.Console/         Терминальный интерфейс, карта и мини-игра рыбалки
assets/music/                      Дефолтный эмбиент и локальная пользовательская музыка
docs/GDD.md                        Дизайн-документ
```
